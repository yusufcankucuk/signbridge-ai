# SignBridge AI

Sağlık odaklı, yapay zeka destekli işaret dili çevirmeni projesi.

## Mimari (Web-First)
Bu proje aşağıdaki bileşenlerden oluşmaktadır:

- **Web (Next.js)**: Kullanıcı arayüzü (App Router, Tailwind CSS, TypeScript).
- **AI (Python)**: İşaret dili tanıma, model eğitimi ve landmark çıkarımı.
- **Cloud (Supabase/GaussDB)**: Veritabanı, API Gateway ve iş kuralları (FunctionGraph).
